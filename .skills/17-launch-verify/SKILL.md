# 17 — Launch Verify (live end-to-end smoke)

Final gate after skill 16 deploys live. Exercises the real production site at
the live `www` host — not localhost — to confirm the funnel actually
works end to end.

## What setup.mjs checks (writes `.supertools-state/17-launch-verify/report.json`)

**Hard (must pass):**
- Apex → www **301** preserving path + query (`$LAUNCH_PROBE_PATH?x=1` → the same path on `www`).
- Funnel + legal pages return 200: `/`, `/quiz`, `/directions`, `/login`,
  `/terms`, `/privacy`, `/refund`, `/contact`, `/privacy-request`.
- `/api/health` → `{ ok: true }`.
- Home HTML carries the OG meta, favicon link, and the Rybbit analytics script.

**Also launch-critical — every one must pass (setup exits non-zero on any failure; verify asserts all):**
- `POST /api/contact` → 2xx (submission accepted into the Chatwoot pipeline).
- `POST /api/checkout` (tier + the just-generated `quizSessionId`) → a URL on
  **`https://sandbox.polar.sh/`** (sandbox is the only non-prod setting).
- **Real generation:** `POST /api/directions/create` with a valid quiz
  submission (enum values read from `src/generation/schemas.ts` so it passes
  validation) → poll `/api/status/directions/:id` until **exactly the 3 style
  directions** are generated by **live OpenAI gpt-4o + fal.ai** (≈$0.13). This is
  the core product working in production; `report.json` records `directionsCount`.
- Cron heartbeat: Healthchecks shows a recent ping (the Worker `scheduled()` is firing).

The `hard`/`verified` split in `report.json` is descriptive only — **all** checks
gate the result.

> Payments stay on Polar **sandbox** (the only non-prod setting). The directions
> generation incurs real API cost (~$0.13) — it's the point of a launch verify.

## Steps

1. ```sh
   node .skills/17-launch-verify/setup.mjs     # runs the live smoke (~2 min, ~$0.13)
   ```
2. ```sh
   node .skills/17-launch-verify/verify.mjs
   ```
   Re-asserts the hard live checks and that the report shows every check passed.
3. Stage candidate, then in-line council + collab review
   (`node .skills/_collab-review/run.mjs 17-launch-verify`).

## Output

- `.supertools-state/17-launch-verify/report.json` — the launch report.
- `.supertools-state/17-launch-verify.json` — receipt.

## Idempotency

Re-runnable; each run is a fresh smoke (and a fresh ~$0.13 generation). Safe —
read-mostly plus one anonymous quiz generation and one sandbox checkout session.
